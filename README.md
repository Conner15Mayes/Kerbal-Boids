# Kerbal-Boids
**A ksp mod that adds an ecology with boids, predators, and space whales to the kerbal system.**

*In active development Adapted code or logic will be credited. Most fish textures will be edited.*

### Dependencies
ModuleManager  
Outer Planets Mod  
Atmospheric Minmus 

### Incompatible  
Real Solar System
